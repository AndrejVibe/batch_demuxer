# batch_demuxer
## Скрипт для массового драг-н-дроп расчленения видео на дорожки

### Как пользоваться
1. Сохраните как demux_all_shared.bat. Надёжнее создать файл и скопировать в него вручную.
2. Положите рядом с ffmpeg.exe и ffprobe.exe.
3. Выделите несколько файлов и перетащите их на батник.
4. Всё окажется в _extracted рядом с первым файлом. Т.к он не трогает оригинал и создаёт копии всего, будет нагрузка на диск.
